# Matgrove1.0 TEST
Native Java/Canvas Android8+ tatami-region placement puzzle. Partition all tiles into non-overlapping rectangles, each containing exactly one shape symbol. A + needs a square, a - needs a wider rectangle, and a | needs a taller rectangle. Four rectangle corners cannot meet at an interior grid point. Tap opposite corners to place, or tap a placed region to remove. Twelve unique 4x4 symbol boards, undo/reset, saved mat palette/region labels, GG007 menu/site/privacy.

Independent Java 100-rectangle shape and exact-cover search checks one solution per board with a set-based four-corner junction oracle. Production shape tests agree on every rectangle; the junction check passes all 625 four-label assignments. Region geometry, bounds, solve, undo, replay, removal and removal undo pass. Adapter menu, settings, privacy, levels, tile taps, win, next and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Not final or Play published.

Registry803 plus ALL local-game scan found no Tatamibari/rectangle-shape-symbol puzzle. Shares rectangle drawing and full coverage with Mosaicmeadow, but replaces exact numbered area with square/wide/tall shape constraints and adds the global no-four-corners junction rule. Legal partitions and solving algorithm change, not just the theme. Known Tatamibari genre, not global invention. Twelve unique symbol boards on one 4x4 size.
